# Design Plan: Glitch-Themed Portfolio

## Overview
A personal "cyber-minimalist" portfolio site for **ThatOneGlitchedGuy (Glitchy Dev)**, inspired by the "break-to-understand" philosophy. The design will feature a blue-black aesthetic with "glitch" animations, terminal-style elements, and a stylized skull logo.

## 1. Visual Identity
- **Color Palette:**
  - Background: Deep Black (`#0a0a0a`)
  - Accent 1: Electric Blue / Cyan (`#00f2ff`)
  - Accent 2: Glitch Magenta / Red (`#ff003c` - for contrast in glitches)
  - Text: Light White / Silver (`#e0e0e0`)
- **Typography:**
  - Monospace fonts (e.g., 'Courier New', 'JetBrains Mono', or 'Roboto Mono') for a terminal feel.
- **Assets:**
  - **Skull Logo:** A CSS-drawn or SVG skull logo with a blue-black-white gradient and glitch effects.

## 2. Technical Stack
- **Framework:** HTML5, Vanilla CSS3 (for performance and flexibility), and Minimalist JavaScript.
- **Architecture:** Single-page application (SPA) style layout with smooth scrolling or tabbed sections.

## 3. Key Features & Components
- **Glitch Hero Section:** A striking landing page with the glitched skull logo and a typing effect for "ThatOneGlitchedGuy" / "Glitchy Dev".
- **System Status Bar:** A persistent or top-level element showing "system online // state: unstable".
- **Project Terminal:** A section displaying projects in a list or card format that mimics a terminal output (`$ ls projects/`).
- **Interactive Glitches:** Hover effects on buttons and links that trigger subtle "RGB shift" or "scramble" animations.
- **CRT Overlay:** An optional scanline and slight flicker effect to enhance the "old terminal" vibe.

## 4. Implementation Steps
1. **Initialize Project:** Create `index.html`, `style.css`, and `script.js`.
2. **Setup Base Styles:** Define colors, fonts, and the CRT/Scanline overlay.
3. **Build Skull Logo:** Create the SVG skull with the specified blue-black-white theme.
4. **Develop Glitch Animations:** Implement CSS keyframes for text and image glitches.
5. **Construct Layout:** Build the Hero, About, Projects, and Contact sections.
6. **Add Interactivity:** Implement the typing effect and hover animations.
7. **Final Polish:** Responsive design check and performance optimization.
